Coptic Fasts & Feasts

An auto-updating Coptic Orthodox liturgical calendar with every event labeled FAST or FEAST, so a glance at the title tells you whether today is a fasting day.

🍃 FAST — vegan abstinence period ✨ FEAST — celebration / fast suspended

Subscribe

Add this URL to Google Calendar, Apple Calendar, or any iCal-compatible app:

https://coptic.petertadrous.com/coptic.ics

Google Calendar: Settings → Add calendar → From URL → paste above.
Apple Calendar: File → New Calendar Subscription → paste above.

How it works

Every Sunday, GitHub Actions fetches the upstream calendar published by the Society of St. Stephen Coptic Orthodox Deacons (valid through 2100), rewrites event titles with FAST/FEAST prefixes, and expands single-day "...Begins" markers into full multi-day fast periods. Set once, runs forever.
